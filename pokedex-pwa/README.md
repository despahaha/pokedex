# Pokédex White (PWA)

Sổ tay cá nhân cho Pokémon White: tiến hóa, nơi bắt, khắc hệ Gen V.
Ứng dụng web cài được, chạy offline sau lần mở đầu tiên.

## Đưa lên GitHub Pages

1. Tạo repo mới trên GitHub (ví dụ `pokedex`), để chế độ Public.
2. Tải toàn bộ file trong thư mục này lên nhánh `main` (giữ nguyên thư mục `fonts/` và `icons/`).
3. Vào Settings → Pages → "Deploy from a branch" → chọn `main`, thư mục `/ (root)` → Save.
4. Chờ khoảng 1 phút, trang sẽ ở `https://<tên-tài-khoản>.github.io/pokedex/`.

## Cài lên iPhone

Mở link trên bằng Safari → nút Chia sẻ → "Thêm vào Màn hình chính".

Dữ liệu lấy từ PokeAPI. Hình minh họa là hình tự vẽ, không phải hình gốc của game.
